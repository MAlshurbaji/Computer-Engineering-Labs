Python · shared setup
import numpy as np
import tensorflow as tf
import keras
import matplotlib.pyplot as plt
keras.utils.set_random_seed(114)
rng = np.random.default_rng(114)

def batches(x, y, batch_size=16, shuffle=False):
    ds = tf.data.Dataset.from_tensor_slices((x, y))
    if shuffle:
        ds = ds.shuffle(len(x), seed=123, reshuffle_each_iteration=True)
    options = tf.data.Options()
    options.threading.private_threadpool_size = 1
    options.threading.max_intra_op_parallelism = 1
    return ds.batch(batch_size).with_options(options)

# Draw paper notes on dark desk backgrounds. Every seventh desk is empty.
def desks(ids):
    images, masks = [], []
    for ident in ids:
        local = np.random.default_rng(900 + int(ident))
        mask = np.zeros((16,16,1),dtype="float32")
        if ident % 7 != 0:
            top, left = local.integers(2,7,size=2)
            height, width = local.integers(5,9,size=2)
            mask[top:top+height,left:left+width,0] = 1
        background = np.full((16,16,3),0.10,dtype="float32")
        color = np.array([0.75,0.80,0.45],dtype="float32")
        image = background*(1-mask) + color*mask
        image = np.clip(image + local.normal(0,0.035,image.shape),0,1)
        images.append(image.astype("float32"))
        masks.append(mask)
    return np.stack(images),np.stack(masks)

train_ids = np.arange(0,64)
val_ids = np.arange(64,80)
test_ids = np.arange(80,96)
x_train, m_train = desks(train_ids)
x_val, m_val = desks(val_ids)
x_test, m_test = desks(test_ids)

def segmenter():
    model = keras.Sequential([
        keras.Input((16,16,3)),
        keras.layers.Conv2D(4,3,padding="same",activation="relu"),
        keras.layers.Conv2D(4,3,padding="same",activation="relu"),
        keras.layers.Conv2D(1,1,activation="sigmoid")
    ])
    model.compile(optimizer=keras.optimizers.Adam(0.005),
                  loss=keras.losses.BinaryCrossentropy())
    return model

# Per-image foreground IoU; an empty prediction with empty truth scores one.
def image_iou(truth, prediction):
    truth, prediction = np.asarray(truth,dtype=bool), np.asarray(prediction,dtype=bool)
    axes = tuple(range(1,truth.ndim))
    intersection = np.sum(truth & prediction,axis=axes)
    union = np.sum(truth | prediction,axis=axes)
    return np.divide(intersection,union,out=np.ones_like(union,dtype=float),where=union!=0)

Guided task 01

Pixel Labels and Mask Alignment

Image classification assigns a label to an entire picture. Segmentation instead assigns a target to each pixel. In this lesson, the foreground class is paper note and the background class is desk. The target mask has one channel: one means note, and zero means background. An empty desk has an all-zero mask.

The setup draws small note rectangles with varied positions and sizes on noisy dark backgrounds. Images use RGB float32 values in zero-to-one, while masks use exact binary values with shape N×16×16×1. A mask is not a colored photograph and should not receive arbitrary image-intensity processing. Its coordinates must remain aligned with the corresponding image.

Inspect image-mask pairs before training. A shifted mask would teach the wrong location even if its shape and values looked reasonable. The three partitions contain different desk identifiers, assigned before model fitting or threshold selection. These simple drawings make the pixel-label relationship easy to see, but real notes have shadows, folds, clutter, and uncertain boundaries that this fixture does not represent.

Guided task 02

Resizing Categorical Masks

Resizing changes the sampling grid of an image or mask. Bilinear interpolation is useful for continuous image intensity because it blends nearby values. A categorical mask has a different meaning: its numbers identify classes. Blending zero and one can create values such as 0.25 that are not valid hard class labels.

Nearest-neighbor resizing selects an existing label for each destination location. For this binary segmentation fixture, that preserves the allowed set of zero and one. It can still change the area or apparent boundary when the resolution changes, because a smaller grid cannot represent every original detail. Preserving labels is not the same as preserving exact geometry.

The task resizes a note mask to eleven by eleven using both methods and displays the result. The unusual target size makes interpolated boundaries easier to see. In a real paired preprocessing pipeline, resize the RGB image and its mask to corresponding spatial dimensions, using image-appropriate interpolation for the pixels and nearest neighbor for categorical labels. Never resize only one member of the pair and assume the original alignment remains valid.

Guided task 03

Paired Spatial Transformations

Segmentation augmentation must move the image and target together. A horizontal reflection sends each image column to the opposite side, and the mask columns must follow the identical mapping. Flipping the picture without its mask would turn a correct annotation into a training error.

This task uses a deterministic reflection so the alignment can be inspected directly. For NHWC batches, width is axis two. The RGB image and single-channel mask have different channel counts, but their batch, height, and width dimensions agree. NumPy slicing with a reversed width axis performs the same geometric change on both arrays; copying creates independent writable arrays.

Not every augmentation affects the mask in the same way. A small brightness change modifies image intensities but normally leaves the class mask unchanged. A translation or rotation modifies geometry and therefore requires a corresponding mask transformation. Keep these roles explicit rather than applying a generic image pipeline independently to the two tensors. The task's paired display makes an otherwise easy-to-miss label alignment requirement visible.

Try it

  1. Flip one image and mask along the width axis.
  2. Keep their channel counts unchanged.
  3. Inspect both transformed tensors and verify that flipping twice restores them.
Python · run in order
image = x_train[1:2]
mask = m_train[1:2]
flipped_image = image[:,:,::-1,:].copy()
flipped_mask = mask[:,:,::-1,:].copy()
fig, axes = plt.subplots(2,2,figsize=(5,5))
axes[0,0].imshow(image[0]); axes[0,0].set_title("Original")
axes[0,1].imshow(flipped_image[0]); axes[0,1].set_title("Reflected")
axes[1,0].imshow(mask[0,:,:,0],cmap="gray",vmin=0,vmax=1)
axes[1,1].imshow(flipped_mask[0,:,:,0],cmap="gray",vmin=0,vmax=1)

Guided task 04

A Fully Convolutional Predictor

A segmentation network must produce a spatial output instead of one class vector per image. The small model here uses two same-padded convolutions followed by a one-by-one convolution with one sigmoid channel. Each output location estimates the probability of paper foreground at the corresponding input location.

The final one-by-one convolution combines local feature channels without collapsing height and width. There is no flattening or dense image-level classification head. Binary cross-entropy compares the foreground probability with the binary target at each pixel. The loss averages many pixel contributions, so a large background region can strongly influence the number even when a foreground object is missed.

Train only on training image-mask pairs and monitor validation loss separately. The network has no external pretrained weights and runs for six short epochs. A decreasing loss indicates optimization progress, while later mask inspection and overlap metrics provide more task-relevant evidence. Do not equate a low pixel loss with correct object boundaries; it is possible to improve the average while retaining important local mistakes.

Try it

  1. Create the small segmentation model.
  2. Fit six epochs on aligned training pairs.
  3. Plot training and validation binary cross-entropy.
Python · run in order
model = segmenter()
history = model.fit(batches(x_train,m_train,shuffle=True),validation_data=batches(x_val,m_val),epochs=6,shuffle=False,verbose=0)
fig, ax = plt.subplots(figsize=(6,3))
ax.plot(history.history["loss"],label="Train")
ax.plot(history.history["val_loss"],label="Validation")
ax.set(xlabel="Epoch index",ylabel="Pixel binary cross-entropy")
ax.legend()
fig.tight_layout()

Read the result

The curves summarize pixel-level loss over many locations. Later tasks inspect probability maps and overlap so that the average does not hide the location or type of segmentation errors.

Guided task 05

Probabilities and Hard Masks

The network outputs continuous probabilities. A hard mask applies a threshold, classifying a pixel as foreground when its probability is at least the selected value. This task starts with 0.5 for inspection, but the next tasks will define a validation-based threshold comparison.

Display the input, ground-truth mask, probability map, and hard prediction together. The probability map can reveal uncertain boundaries that a binary image hides. Keep its color scale fixed at zero to one so different examples remain comparable. The hard-mask comparison uses the same spatial coordinates as the truth.

Pixel accuracy is easy to compute but can be misleading when background dominates. A predictor that calls every pixel background will correctly label all actual background locations while completely missing each note. Compute that all-background baseline on validation masks to see the class-balance effect. This does not mean pixel accuracy is always useless; it means the metric answers a different question from foreground overlap. A useful evaluation reports an overlap measure and interprets it with the visible masks and class prevalence.

Try it

  1. Predict validation foreground probabilities.
  2. Threshold at 0.5 for an initial visual inspection.
  3. Compute the all-background pixel-accuracy baseline.

Guided task 06

Foreground Intersection over Union

Foreground intersection over union compares the predicted and true foreground sets. The intersection counts pixels marked foreground by both masks. The union counts pixels marked foreground by either mask. Dividing intersection by union penalizes both missed foreground and extra foreground while excluding correctly predicted background from the numerator.

An empty union requires an explicit convention. This lesson assigns IoU one when both masks are empty, because prediction and truth agree that no foreground exists. If only one mask is empty, the union is nonzero and the intersection is zero, giving IoU zero. Other reporting protocols may handle empty images differently, so the convention belongs beside the result.

The small numeric example makes the calculation auditable before applying it to model outputs. We compute one IoU per image and later average those values, giving each desk equal weight. This macro average differs from summing all intersections and unions before division, which weights larger foreground unions more strongly. Neither aggregation should be reported under an ambiguous label. Name the foreground class, empty-mask rule, and averaging method.

Try it

  1. Compute intersection and union for the supplied small masks.
  2. Check empty-empty and empty-nonempty cases.
  3. Display truth, prediction, and their intersection.
Python · run in order
truth = np.array([[1,1,0],[0,1,0]],dtype=bool)
prediction = np.array([[1,0,1],[0,1,0]],dtype=bool)
intersection = int(np.sum(truth & prediction))
union = int(np.sum(truth | prediction))
example_iou = intersection/union if union else 1.0
empty_scores = image_iou(np.zeros((2,2,2,1)),np.array([np.zeros((2,2,1)),np.ones((2,2,1))]))
fig, axes = plt.subplots(1,3,figsize=(7,3))

    ax.imshow(panel,cmap="gray",vmin=0,vmax=1)

Guided task 07

Threshold Selection on Validation Data

Threshold selection is a model-development decision. Compare the fixed candidate thresholds 0.3, 0.5, and 0.7 using the validation probability maps and masks. For each candidate, compute per-image foreground IoU with the established empty rule, then average across validation desks.

The chosen threshold is the candidate with the largest mean validation IoU. An exact tie uses the first candidate, which is the lowest threshold in this ordered list. Specifying the tie rule makes the procedure reproducible. It does not imply that lower thresholds are always preferable; the rule simply resolves an otherwise identical measured score.

A threshold changes the balance between extra foreground and missed foreground. Lowering it generally marks more pixels as paper, while raising it marks fewer. The best value depends on score quality, class balance, and application costs. This exercise uses IoU as the stated objective, but a document-cropping tool might impose additional requirements about preserving all text. Keep the test masks untouched while selecting the threshold, and avoid revising the candidate list after inspecting final test results.

Try it

  1. Evaluate the three supplied thresholds on validation masks.
  2. Choose the largest mean per-image IoU with the stated tie rule.
  3. Plot candidate thresholds against measured validation IoU.
Python · run in order
thresholds = np.array([0.3,0.5,0.7])
validation_iou = np.array([image_iou(m_val,val_probabilities>=threshold).mean() for threshold in thresholds])
best_index = int(np.argmax(validation_iou))
chosen_threshold = float(thresholds[best_index])
fig, ax = plt.subplots(figsize=(6,3))
ax.plot(thresholds,validation_iou,"o-")
ax.set(xlabel="Foreground threshold",ylabel="Mean validation image IoU",ylim=(0,1.05))

fig.tight_layout()

Guided task 08

Final Segmentation Evaluation

After the network and threshold are fixed, evaluate the reserved test desks. Generate probabilities in inference mode, apply the selected threshold, and calculate per-image foreground IoU with exactly the same convention used for validation. Report the mean together with the individual values rather than hiding the variation between empty and nonempty scenes.

The plotted examples show input, truth, and prediction for several test desks. Inspect false foreground on an empty desk, missing note edges, and extra regions around a note. A scalar overlap score tells how much the masks disagree, but the image panels show where and in what form that disagreement occurs.

A final evaluation should preserve the data and metric definitions: RGB scaling, foreground class, threshold, mask interpolation policy, empty-union rule, and aggregation method. The result applies to the held-out drawings, not to arbitrary photographs of a desk. Moving toward a real application would require new annotated examples, careful boundary definitions, and a fresh evaluation set containing the expected clutter and lighting. This completed workflow provides a repeatable starting point rather than a claim of production-ready segmentation.
