Python · shared setup
import numpy as np
import tensorflow as tf
import keras
import matplotlib.pyplot as plt
keras.utils.set_random_seed(113)
rng = np.random.default_rng(113)
class_names = ["cup", "bottle"]

def batches(x, y, batch_size=16, shuffle=False):
    ds = tf.data.Dataset.from_tensor_slices((x, y))
    if shuffle:
        ds = ds.shuffle(len(x), seed=123, reshuffle_each_iteration=True)
    options = tf.data.Options()
    options.threading.private_threadpool_size = 1
    options.threading.max_intra_op_parallelism = 1
    return ds.batch(batch_size).with_options(options)

# A group is one drawn object; its two noisy views must stay together.
def pictures(group_ids, tint=False):
    images, labels, groups = [], [], []
    for gid in group_ids:
        local = np.random.default_rng(int(gid) + 800)
        label = int(gid) % 2
        shift = int(local.integers(-1, 2))
        base = np.zeros((16, 16), dtype=np.float32)
        if label == 0:
            base[6:13, 4+shift:10+shift] = 0.85
            base[7:11, 10+shift:12+shift] = 0.85
            base[8:10, 10+shift:11+shift] = 0
        else:
            base[3:6, 7+shift:9+shift] = 0.85
            base[6:13, 5+shift:11+shift] = 0.85
        for view in range(2):
            image = np.repeat(base[..., None], 3, axis=-1)
            if tint:
                image = image * np.array([0.7, 0.9, 1.0], dtype=np.float32)
            image = np.clip(image + local.normal(0, 0.025, image.shape), 0, 1)
            images.append(image.astype("float32"))
            labels.append(label)
            groups.append(gid)
    return np.stack(images), np.array(labels, dtype="int32"), np.array(groups)

train_ids = np.arange(0, 32)
val_ids = np.arange(32, 40)
test_ids = np.arange(40, 48)
x_train, y_train, g_train = pictures(train_ids)
x_val, y_val, g_val = pictures(val_ids)
x_test, y_test, g_test = pictures(test_ids)

def classifier(augmentation=None):
    inputs = keras.Input((16, 16, 3))
    z = inputs if augmentation is None else augmentation(inputs)
    z = keras.layers.Conv2D(4, 3, padding="same", activation="relu", name="features")(z)
    z = keras.layers.MaxPooling2D()(z)
    z = keras.layers.Flatten()(z)
    outputs = keras.layers.Dense(2, name="scores")(z)
    model = keras.Model(inputs, outputs)
    model.compile(optimizer=keras.optimizers.Adam(0.005),
                  loss=keras.losses.SparseCategoricalCrossentropy(from_logits=True),
                  metrics=["accuracy"])
    return model

# Interpretation helpers operate on a supplied model; they do not train one.
def input_saliency(model, images, target):
    tensor = tf.convert_to_tensor(images)
    with tf.GradientTape() as tape:
        tape.watch(tensor)
        score = tf.reduce_sum(model(tensor, training=False)[:, target])
    gradients = tape.gradient(score, tensor)
    return tf.reduce_max(tf.abs(gradients), axis=-1).numpy()

def scale_map(values):
    values = np.asarray(values, dtype=np.float32)
    maximum = float(values.max())
    return values / maximum if maximum > 0 else np.zeros_like(values)

Guided task 01

A Trained Model to Inspect

Interpretation begins with a defined model and a concrete question. We train a small CNN to distinguish drawn cups from bottles, then inspect its behavior on validation objects it did not train on. The class order is cup then bottle, and the final dense layer returns two logits. Every later visualization in this lesson refers to this trained model rather than an untrained random network.

The setup provides independent object-group partitions and a fixed zero-to-one RGB scale. Five short training epochs keep computation modest. Plot training and validation losses to confirm that optimization ran and remained finite. We also compare initial and final weights. Changed weights establish learning activity; they do not establish that the model learned the same visual reasoning a person would use.

Keep the interpretation purpose narrow. A heatmap can suggest locations to investigate, but it is not a complete account of the model or a causal proof. The generator offers a small set of clean shapes, which makes visual inspection manageable while limiting the conclusions. Record which image, target class, and model stage produced each visualization so comparisons remain meaningful.

Try it

  1. Train a fresh classifier for five epochs.
  2. Check finite losses and changed parameters.
  3. Retain this trained model for subsequent tasks.

before = [w.copy() for w in model.get_weights()]
history = model.fit(batches(x_train,y_train,shuffle=True),validation_data=batches(x_val,y_val),epochs=5,shuffle=False,verbose=0)
fig, ax = plt.subplots(figsize=(6,3))

Guided task 02

Scores, Probabilities, and Targets

A class score and an explanation target are related but distinct choices. The network returns logits, which can be positive or negative and do not sum to one. Applying softmax converts the pair into a probability distribution over the two configured classes. The largest logit and largest softmax probability identify the same predicted label.

Choose one validation picture and record its true label, predicted label, and the target class to inspect. In this task the target is the predicted class. Later we can deliberately inspect the other class while keeping the input fixed. Without an explicit target, two heatmaps may appear inconsistent simply because they explain different score coordinates.

A large predicted probability is not a guarantee of correctness, calibration, or familiarity with the scene. This model only distinguishes two kinds of drawn object and must distribute its softmax mass between those classes even for an unsuitable input. The bar chart summarizes this particular forward pass. It does not explain which pixels produced the decision; the gradient and feature-map tasks ask that separate question.

Try it

  1. Select the first validation picture.
  2. Compute logits, probabilities, and the predicted target index.
  3. Plot the picture next to its probability bars.
Python · run in order
sample = x_val[:1]
logits = model(sample,training=False).numpy()[0]
probabilities = tf.nn.softmax(logits).numpy()
target = int(np.argmax(logits))
fig, axes = plt.subplots(1,2,figsize=(7,3))
axes[0].imshow(sample[0]); axes[0].axis("off")
axes[0].set_title("True: "+class_names[y_val[0]])
axes[1].bar(class_names,probabilities)
axes[1].set(ylim=(0,1),ylabel="Softmax probability",title="Target: "+class_names[target])
fig.tight_layout()

Read the result

The bars sum to one across the two configured classes. Keep the target index with the image; subsequent explanations must refer to the same coordinate unless the task explicitly asks for another class.

  • Compare the winning logit with the winning probability index.

Guided task 03

Intermediate Feature Maps

A convolutional layer produces a set of spatial response maps. Each channel has a learned filter and can respond differently across the image. The named features layer in this model has four filters and same padding, so each map has the original 16×16 spatial size before pooling.

Build a second Keras Model that shares the trained input and ends at the features layer. This inspection model does not retrain or copy random weights; it exposes an intermediate tensor from the existing trained network. Display the four channel maps using a shared color scale, which makes relative activation magnitudes comparable across channels for this input.

A feature map is not automatically a class explanation. It shows where one channel responds, but the final classifier combines many locations and channels. A bright response may support, oppose, or have little effect on a particular class score after downstream weights are considered. Avoid naming a channel as a handle detector based on one picture alone. Inspecting several objects can generate a hypothesis, while target-specific gradient weighting will address a different question in a later task.

Try it

  1. Expose the trained features layer as an inspection model.
  2. Compute its tensor for the selected image.
  3. Plot all channels with one shared intensity scale.
Python · run in order
feature_model = keras.Model(model.input,model.get_layer("features").output)
feature_maps = feature_model(sample,training=False).numpy()[0]
fig, axes = plt.subplots(1,4,figsize=(9,3))
upper = max(float(feature_maps.max()),1e-8)
for channel, ax in enumerate(axes):
    ax.imshow(feature_maps[:,:,channel],cmap="magma",vmin=0,vmax=upper)
    ax.set_title("Channel "+str(channel))
    ax.axis("off")
fig.tight_layout()

Read the result

These are measured activations of learned convolution filters. The shared scale prevents an almost inactive channel from looking equally strong merely because its own display was stretched. Brightness alone does not identify a target-class contribution.

Change and compare

  • Inspect the same channels for a second class.
  • Compare a shared display scale with separate per-map scaling.

Guided task 04

Input-gradient Saliency

A gradient describes local sensitivity: how a chosen output score would change for a very small change in an input coordinate near the current image. For input saliency, watch the input tensor with GradientTape, compute the selected logit, and differentiate that logit with respect to the pixels.

The helper takes the largest absolute gradient across the RGB channels at each location. Taking an absolute value discards the direction of influence, so the resulting map reports sensitivity magnitude rather than support versus opposition. The selected score is a logit rather than a softmax probability; softmax coupling can otherwise mix the sensitivity of multiple class scores.

Scale the display by the largest map value, guarding the all-zero case. This normalization makes the image readable but hides the original absolute gradient scale. A bright pixel means high relative local sensitivity in this particular map. It does not mean the pixel is an object part, that removing it causes the same response, or that the model is using a human-like explanation. Large finite changes require separate experiments.

Try it

  1. Differentiate the chosen logit with respect to the input.
  2. Reduce absolute gradients across RGB channels.
  3. Display the original image and the normalized sensitivity map.
Python · run in order
saliency = input_saliency(model,sample,target)[0]
saliency_display = scale_map(saliency)
fig, axes = plt.subplots(1,2,figsize=(6,3))
axes[0].imshow(sample[0]); axes[0].set_title("Input")
axes[1].imshow(saliency_display,cmap="inferno",vmin=0,vmax=1)
axes[1].set_title("Input sensitivity")
for ax in axes: ax.axis("off")
fig.tight_layout()

Read the result

The map visualizes the magnitude of a local derivative from the trained model. Normalization is for display only. Keep the original saliency array if comparing absolute sensitivities across examples or model versions.

Change and compare

  • Inspect the unnormalized maximum gradient.
  • Explain what information absolute value removes.

Guided task 05

Target-specific Comparisons

The same picture can be inspected with respect to different class scores. Holding the image and model fixed while changing only the target index helps reveal that an explanation is tied to a question. One map asks about sensitivity of the cup score; the other asks about sensitivity of the bottle score.

Compute both raw saliency maps, then use a single shared maximum to display them. Separately normalizing each map would emphasize spatial patterns but could conceal large differences in total magnitude. The shared scale preserves a relative magnitude comparison for this one pair. It still does not recover the gradient signs discarded by the absolute-value reduction.

Similar-looking maps are not necessarily an error. Two class scores may depend on overlapping visual evidence, with different directions or downstream combinations. Conversely, different maps do not establish that the network has discovered distinct physical object parts. Interpretation requires stating the target, reduction, and scaling choices. Record those choices before using the plots to support a narrative about what a classifier appears sensitive to.

Try it

  1. Compute saliency for class zero and class one.
  2. Choose a common display maximum.
  3. Compare both maps for the exact same validation picture.
Python · run in order
class_maps = np.stack([input_saliency(model,sample,c)[0] for c in range(2)])
shared_max = max(float(class_maps.max()),1e-8)
fig, axes = plt.subplots(1,2,figsize=(6,3))
for c, ax in enumerate(axes):
    ax.imshow(class_maps[c],cmap="inferno",vmin=0,vmax=shared_max)
    ax.set_title(class_names[c]+" logit")
    ax.axis("off")
fig.tight_layout()

Read the result

The maps share the input, model, reduction, and display scale. Their only planned change is the target class. This controlled comparison makes differences interpretable without suggesting that either map is a complete causal explanation.

Change and compare

  • Compare the sum of raw magnitudes across targets.
  • Explain how separate normalization could change the visual impression.

Guided task 06

Gradient-weighted Activation Maps

Grad-CAM combines spatial feature maps with target-specific gradient weights. Differentiate the selected logit with respect to the convolutional feature tensor, average each channel's gradient across spatial positions, and use those averages to form a weighted sum of the channel maps. A final ReLU keeps the positive part of that combined map.

This model's chosen convolution retains 16×16 resolution, so its Grad-CAM map already matches the input dimensions. Many larger CNNs produce a smaller feature map and require resizing for an overlay. Resizing would improve display alignment, not create new localization detail. The selected layer and its resolution should accompany any reported map.

The gradient model returns both the feature tensor and logits from one shared trained forward pass. This keeps the tensor being differentiated connected to the target computation. Normalize the positive map with an explicit zero guard, then overlay it on the original picture. Treat highlighted regions as coarse target-related localization clues. Grad-CAM does not prove that only the highlighted pixels caused the prediction, and its appearance can change with the chosen layer.

Try it

  1. Expose features and logits together from the trained model.
  2. Compute target gradients and channel-average weights.
  3. Display the normalized positive weighted map as an overlay.
Python · run in order
gradient_model = keras.Model(model.input,[model.get_layer("features").output,model.output])
with tf.GradientTape() as tape:
    activations, scores = gradient_model(tf.convert_to_tensor(sample),training=False)
    selected_score = scores[0,target]
feature_gradients = tape.gradient(selected_score,activations)
channel_weights = tf.reduce_mean(feature_gradients,axis=(0,1,2))
weighted = tf.reduce_sum(activations[0]*channel_weights,axis=-1)
cam = scale_map(tf.nn.relu(weighted).numpy())
fig, axes = plt.subplots(1,2,figsize=(6,3))
axes[0].imshow(cam,cmap="inferno",vmin=0,vmax=1); axes[0].set_title("Grad-CAM")
axes[1].imshow(sample[0]); axes[1].imshow(cam,cmap="inferno",alpha=0.5,vmin=0,vmax=1)
axes[1].set_title("Overlay")
for ax in axes: ax.axis("off")
fig.tight_layout()

Read the result

The overlay comes from learned feature maps and gradients of the stated target score. A zero map is handled safely and should be reported rather than replaced with a fabricated highlight. The overlay's color scale is relative to this map.

Change and compare

  • Inspect the four channel weights numerically.
  • Explain why resizing a coarse map cannot add new model evidence.

Guided task 07

Finite Occlusion Experiments

A gradient describes an infinitesimal local change. Occlusion instead replaces a visible patch with a chosen baseline and measures a finite score difference. Here the baseline is black, matching the background, and each patch is four pixels square. The target class stays fixed throughout the comparison.

Measure the original target logit once. For each nonoverlapping patch, create a separate copy of the image, cover that patch, and subtract the covered-image target logit from the original. A positive drop means this particular cover reduced the chosen score; a negative value means the score increased. Keep the sign instead of clipping away results that do not match an expected story.

The heatmap has four rows and four columns because the experiment covers sixteen patches, not individual pixels. Its values depend on patch size, location, and replacement color. Occlusion can create unrealistic images and interactions among patches, so it still does not provide a complete causal account. It complements saliency by asking a different, explicitly specified intervention question.

Try it

  1. Hold the target index fixed.
  2. Cover each four-by-four patch in a separate image copy.
  3. Plot signed target-logit drops on the patch grid.
Python · run in order
original_score = float(model(sample,training=False).numpy()[0,target])
drops = np.zeros((4,4),dtype=np.float32)
for r in range(4):
    for c in range(4):
        occluded = sample.copy()
        occluded[:,r*4:(r+1)*4,c*4:(c+1)*4,:] = 0
        drops[r,c] = original_score-float(model(occluded,training=False).numpy()[0,target])
limit = max(float(np.max(np.abs(drops))),1e-8)
fig, ax = plt.subplots(figsize=(4,3))
im = ax.imshow(drops,cmap="coolwarm",vmin=-limit,vmax=limit)
ax.set(xlabel="Patch column",ylabel="Patch row")
fig.colorbar(im,ax=ax,label="Target-logit drop")
fig.tight_layout()

Read the result

Red and blue indicate opposite directions of score change under the stated cover operation. Each cell summarizes a patch, not a single input coordinate. Differences from a gradient map are expected because the intervention and resolution differ.

Change and compare

  • Try a gray replacement in a separate comparison.
  • Explain why changing the target after each cover would change the question.

Guided task 08

Stability and Interpretation Limits

An explanation should be checked for sensitivity to small input changes, not only judged by its most attractive image. Add a fixed low-amplitude noise perturbation to the chosen validation picture, keep the same target index, and recompute input saliency. This isolates input sensitivity of the explanation from the separate effect of switching explanation targets.

Compare raw saliency values before display normalization. The mean absolute map difference gives one numerical summary, while the two maps reveal where changes occurred. This number is not a universal stability score: its scale depends on the model, score units, gradient reduction, and perturbation strength. Report those settings alongside it.

A stable explanation is not automatically correct, and an unstable one is not automatically useless. The exercise is an audit of a specific visualization procedure. Combine learned feature inspection, target-specific gradients, and explicit occlusion experiments with ordinary evaluation and data inspection. When reporting to another person, describe the maps as sensitivity or localization clues and state the drawn-data scope. Avoid converting a suggestive colored region into a claim that the network understands a physical object part.

Try it

  1. Add seeded noise with standard deviation 0.01.
  2. Recompute saliency for the unchanged target class.
  3. Compare raw map differences and display both maps.
Python · run in order
noise_rng = np.random.default_rng(809)
nearby = np.clip(sample+noise_rng.normal(0,0.01,sample.shape),0,1).astype("float32")
nearby_saliency = input_saliency(model,nearby,target)[0]
map_difference = float(np.mean(np.abs(nearby_saliency-saliency)))
upper = max(float(max(saliency.max(),nearby_saliency.max())),1e-8)
fig, axes = plt.subplots(1,3,figsize=(9,3))
axes[0].imshow(nearby[0]); axes[0].set_title("Perturbed input")
axes[1].imshow(saliency,cmap="inferno",vmin=0,vmax=upper); axes[1].set_title("Original map")
axes[2].imshow(nearby_saliency,cmap="inferno",vmin=0,vmax=upper); axes[2].set_title("Nearby map")
for ax in axes: ax.axis("off")
print("Raw-map mean absolute difference:",map_difference,"target:",class_names[target])
fig.tight_layout()

Read the result

The shared map scale makes the pair easier to compare. The reported difference belongs to this fixed perturbation and target. It should support a careful description of stability, not a claim that a heatmap proves causation or semantic understanding.

  • Repeat with a different noise seed.
  • Write one appropriately limited conclusion about the observed maps.
