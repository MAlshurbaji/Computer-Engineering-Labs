Guided task 01

Spatial axes and channels

An image tensor carries several different kinds of axes. Height and width locate pixels; channels hold values at the same location; a batch axis groups separate images. The supplied bottle is one sixteen-by-sixteen RGB drawing with float values between zero and one. Adding a leading axis creates a batch of one without changing any pixel values. Keeping these meanings separate prevents a common mistake: treating the three color channels as three neighboring image columns.

For the first filter calculations, average the three channels to create one scalar brightness-like value per pixel. This equal-channel average is a convenient teaching transformation, not a calibrated luminance measurement. Preserve the last axis so the grayscale tensor has one channel rather than losing its channel dimension. The plot compares the original colors with this transformed representation. A filter receiving the grayscale image cannot recover which original channel contributed most. That loss of color information is a deliberate simplification, useful for tracing spatial operations before returning to multiple input channels.

Try it

  1. Add a batch axis to the supplied RGB drawing.
  2. Create a one-channel mean image with keepdims=True.
  3. Display RGB and one-channel views and print their tensor shapes.
Python · run in order
rgb_batch = image[None, ...]
gray = image.mean(axis=-1, keepdims=True)[None, ...]
print('RGB:', rgb_batch.shape, 'Gray:', gray.shape)
fig, axes = plt.subplots(1, 2, figsize=(7, 3))
axes[0].imshow(image)
axes[0].set_title('Drawn RGB bottle')
axes[1].imshow(gray[0, :, :, 0], cmap='gray', vmin=0, vmax=1)
axes[1].set_title('Equal-channel mean')
for ax in axes:
    ax.set(xlabel='Column', ylabel='Row')
fig.tight_layout()

Read the result

Both panels refer to the same spatial grid. The mean view removes color differences while preserving one value at every row and column.

Change and compare

  • Inspect one cap pixel and one bottle-body pixel in RGB.
  • Explain which axis keepdims preserves in this operation.

Guided task 02

One patch produces one response

A filter response begins with a small patch and a same-sized grid of weights. Multiply entries at matching positions, then add the products. The demonstration uses a three-by-three patch straddling the bottle’s left side and a kernel with negative weights on the left and positive weights on the right. A brighter right side can therefore produce a positive response. Reversing the contrast can produce a negative response.

The TensorFlow operation used later follows the common neural-network convention of cross-correlation: it uses the supplied kernel orientation directly rather than flipping it first. Libraries often call this convolution in the layer name. State the convention when doing a hand calculation so a sign difference does not become mysterious. The response is a weighted local contrast, not a probability or a detected object label. Its scale can exceed the original zero-to-one pixel range because several weighted values are added. Inspecting the elementwise product map is a useful way to find a wrong patch position or an accidentally reversed kernel.

Try it

  1. Take rows five through seven and columns four through six of the mean image.
  2. Multiply that patch by the supplied three-by-three kernel.
  3. Show the patch, kernel and products; print their summed response.
Python · run in order
gray = image.mean(axis=-1)
patch = gray[5:8, 4:7]
kernel = np.array([[-1, 0, 1], [-1, 0, 1], [-1, 0, 1]], dtype='float32')
products = patch * kernel
response = float(products.sum())
print('One response:', response)
fig, axes = plt.subplots(1, 3, figsize=(9, 3))
for ax, values, title in zip(axes, [patch, kernel, products], ['Patch', 'Kernel', 'Products']):
    ax.imshow(values, cmap='coolwarm')
    ax.set_title(title)
    for row in range(3):
        for col in range(3):
            ax.text(col, row, f'{values[row, col]:.2f}', ha='center', va='center', color='black', bbox=dict(facecolor='white', alpha=0.7, edgecolor='none'))
fig.tight_layout()

Read the result

The summed response follows the product values, including their signs. A large response means agreement with this local contrast rule, not recognition of the entire bottle.

Change and compare

  • Negate the kernel and predict the response sign.
  • Move the patch to a uniform background area.

Guided task 03

Shared kernels create feature maps

A feature map repeats one local rule at many positions. Sharing the same kernel across the image means the detector does not need a separate set of weights for every location. With valid padding, the three-by-three window is evaluated only where it fits entirely inside the sixteen-by-sixteen input, producing fourteen positions along each spatial axis.

The filter tensor includes two channel axes: input channels and output filters. For a one-channel image and one filter, its shape is three by three by one by one. The output retains the batch axis and has one feature-map channel. Compare the map with the image and remember that output position zero corresponds to a patch beginning at input position zero under valid padding. This spatial correspondence is useful, but a local edge response remains far simpler than an object decision. The kernel is supplied here, not learned. A trained CNN will optimize such weights from a loss while using the same spatial calculation and sharing pattern.

Try it

  1. Reshape the supplied directional kernel to height, width, input channels and output filters.
  2. Apply tf.nn.conv2d with stride one and VALID padding.
  3. Display the complete signed response map beside the input.
Python · run in order
gray_batch = image.mean(axis=-1, keepdims=True)[None, ...]
kernel = np.array([[-1, 0, 1]] * 3, dtype='float32')[:, :, None, None]
feature_map = tf.nn.conv2d(gray_batch, kernel, strides=1, padding='VALID').numpy()
fig, axes = plt.subplots(1, 2, figsize=(7, 3))
axes[0].imshow(gray_batch[0, :, :, 0], cmap='gray', vmin=0, vmax=1)
axes[0].set_title('Input, 16 by 16')
limit = float(np.abs(feature_map).max())
axes[1].imshow(feature_map[0, :, :, 0], cmap='coolwarm', vmin=-limit, vmax=limit)
axes[1].set_title('Signed map, 14 by 14')
fig.tight_layout()

Read the result

Opposite contrast directions can produce opposite signs. The color scale is centered at zero so positive and negative evidence can be compared fairly.

Change and compare

  • Check one output cell against a hand-calculated input patch.
  • Explain why the output has one channel even though the kernel has nine spatial entries.

Guided task 04

Padding changes border assumptions

Valid padding discards locations where the full kernel would fall outside the input. Same padding instead adds values around the border so a stride-one output keeps the input’s spatial dimensions. For the TensorFlow operation used here, the added values are zeros. That is an assumption about missing neighbors, not extra observed image content.

A three-by-three averaging kernel makes this difference easy to see. Near a border, zero padding can reduce an average even when the visible image begins with a uniform nonzero background. In the valid output, every average uses nine real input pixels. Interior values shared by both calculations should agree; the difference is the set of available output locations and the added border context. Do not describe same padding as always preserving all information without change. It preserves dimensions under the stated stride, but changes the neighborhoods used at the edges. Border policy belongs in a model’s preprocessing and architecture description because it affects numerical responses.

Try it

  1. Use a three-by-three kernel whose nine weights sum to one.
  2. Apply it with VALID and SAME padding at stride one.
  3. Compare shapes, border values and the matching interior region.
Python · run in order
gray_batch = image.mean(axis=-1, keepdims=True)[None, ...]
average_kernel = np.ones((3, 3, 1, 1), dtype='float32') / 9
valid_map = tf.nn.conv2d(gray_batch, average_kernel, 1, 'VALID').numpy()
same_map = tf.nn.conv2d(gray_batch, average_kernel, 1, 'SAME').numpy()
fig, axes = plt.subplots(1, 2, figsize=(7, 3))
for ax, values, title in zip(axes, [valid_map, same_map], ['VALID: 14 by 14', 'SAME: 16 by 16']):
    ax.imshow(values[0, :, :, 0], cmap='gray', vmin=0, vmax=1)
    ax.set_title(title)
fig.tight_layout()

Read the result

The central SAME region matches VALID, while the outer SAME border uses zero neighbors. Both panels use the same brightness limits so border differences remain interpretable.

Change and compare

  • Check the top-left SAME average using the visible two-by-two corner and five zeros.
  • Explain why equal output dimensions do not imply an unchanged border response.

Guided task 05

Stride changes sampling locations

Stride controls how far the window moves between neighboring output locations. A stride of two samples fewer window positions than a stride of one. It does not automatically double the kernel’s size or add more learned weights. With the same valid three-by-three kernel, the sixteen-pixel input gives fourteen output locations at stride one and seven at stride two along each axis.

The stride-two responses in this case match every other location of the stride-one result, beginning at its top-left cell. That equivalence depends on using the same kernel, padding convention and origin. Fewer responses reduce spatial resolution; small shifts in the input can then change which details land at sampled locations. Downsampling may be useful computationally, but it is not a promise of invariance to every translation. Compare actual map values as well as dimensions. In a CNN, a later layer receives the reduced grid and cannot recover all skipped detail merely because the original image had more pixels.

Try it

  1. Apply the same averaging kernel with valid padding at strides one and two.
  2. Compare the output shapes and corresponding sampled positions.
  3. Display both feature maps with common intensity limits.
Python · run in order
gray_batch = image.mean(axis=-1, keepdims=True)[None, ...]
kernel = np.ones((3, 3, 1, 1), dtype='float32') / 9
stride_one = tf.nn.conv2d(gray_batch, kernel, strides=1, padding='VALID').numpy()
stride_two = tf.nn.conv2d(gray_batch, kernel, strides=2, padding='VALID').numpy()
fig, axes = plt.subplots(1, 2, figsize=(7, 3))
for ax, values, title in zip(axes, [stride_one, stride_two], ['Stride 1', 'Stride 2']):
    ax.imshow(values[0, :, :, 0], cmap='gray', vmin=0, vmax=1)
    ax.set_title(title)
fig.tight_layout()

Read the result

The lower-resolution map samples selected windows from the same underlying computation. A smaller display grid does not mean the original bottle itself became physically smaller.

Change and compare

  • Locate which stride-one cells correspond to stride-two output row zero.
  • Predict the valid output width for a stride of three before running it.

Guided task 06

Input channels and multiple output filters

A filter can combine channels at the same spatial location as well as combine neighboring locations. A one-by-one kernel is a clean example: it does not look at neighboring pixels, but can mix red, green and blue into new feature values. Each output filter has a separate weight for each input channel. Two output filters therefore produce two maps, even though the original image has three channels.

The first supplied filter computes red minus green, and the second computes the equal-channel average. Their kernel shape is one by one by three by two. Negative values in the first map are legitimate signed responses, not invalid RGB colors, because a feature map need not remain in the input range. The second map summarizes brightness by the stated simple rule. These hand-chosen filters demonstrate channel mixing without a training loop. A learned one-by-one convolution uses the same calculation while allowing its weights to be optimized for a task. Keep the distinction between channel mixing and spatial neighborhood size explicit.

Try it

  1. Build a one-by-one kernel with three input channels and two output filters.
  2. Assign red-minus-green weights to one filter and averaging weights to the other.
  3. Display the original image and both output maps.
Python · run in order
channel_kernel = np.zeros((1, 1, 3, 2), dtype='float32')
channel_kernel[0, 0, :, 0] = [1, -1, 0]
channel_kernel[0, 0, :, 1] = [1/3, 1/3, 1/3]
channel_maps = tf.nn.conv2d(image[None, ...], channel_kernel, 1, 'VALID').numpy()
fig, axes = plt.subplots(1, 3, figsize=(9, 3))
axes[0].imshow(image)
axes[0].set_title('RGB input')
axes[1].imshow(channel_maps[0, :, :, 0], cmap='coolwarm', vmin=-1, vmax=1)
axes[1].set_title('Red minus green')
axes[2].imshow(channel_maps[0, :, :, 1], cmap='gray', vmin=0, vmax=1)
axes[2].set_title('Channel mean')
fig.tight_layout()

Read the result

The cap and body can have different signs in the color-difference map. Two output channels arise from two filters, not from discarding one of the three input channels.

Change and compare

  • Exchange the red and green signs in the first filter.
  • Describe what a one-by-one filter cannot observe about neighboring pixels.

Guided task 07

ReLU changes signed evidence

A linear filter can respond positively to one contrast direction and negatively to the opposite. ReLU replaces negative values with zero while retaining positive values. It introduces a nonlinear operation between layers, and changes what information the next layer receives. After ReLU, absence of a positive response does not distinguish a negative response from an exact zero.

The input and supplied directional kernel are the same type used earlier, so this experiment isolates the activation step. Display the signed map with a zero-centered diverging scale and the rectified map with a nonnegative scale. The two color conventions prevent a negative value from being mistaken for a weak positive one. ReLU is not normalization and does not force every value into the interval zero to one. Large positive responses remain large. A CNN can learn multiple filters with different orientations or signs, but that additional capacity is separate from this one filter’s rectification. Trace the numbers before giving a feature map an intuitive label such as an edge detector.

Try it

  1. Compute the supplied signed directional map.
  2. Apply tf.nn.relu to that map.
  3. Compare negative locations and the unchanged positive responses.
Python · run in order
gray_batch = image.mean(axis=-1, keepdims=True)[None, ...]
kernel = np.array([[-1, 0, 1]] * 3, dtype='float32')[:, :, None, None]
signed = tf.nn.conv2d(gray_batch, kernel, 1, 'VALID').numpy()
rectified = tf.nn.relu(signed).numpy()
limit = float(np.abs(signed).max())
fig, axes = plt.subplots(1, 2, figsize=(7, 3))
axes[0].imshow(signed[0, :, :, 0], cmap='coolwarm', vmin=-limit, vmax=limit)
axes[0].set_title('Signed response')
axes[1].imshow(rectified[0, :, :, 0], cmap='magma', vmin=0, vmax=limit)
axes[1].set_title('After ReLU')
fig.tight_layout()

Read the result

Negative responses disappear while positive numerical values stay unchanged. The right panel is a feature map, not a grayscale photograph or a class-probability image.

Change and compare

  • Count positive, negative and zero responses before rectification.
  • Explain why two different signed maps can become identical after ReLU.

Guided task 08

Pooling summarizes local regions

Pooling reduces a spatial grid using a fixed summary rule. Max pooling keeps the largest value in each window, while average pooling keeps the mean. Neither of these layers learns a kernel in this demonstration. With two-by-two windows and stride two, the sixteen-by-sixteen input becomes eight by eight without overlapping windows.

The rules preserve different information. A single bright pixel can dominate a max-pooled cell but has less influence on its average. Both summaries lose the original arrangement inside the window, so many different patches can produce the same result. That loss can be useful for reducing computation or sensitivity to some small changes, but it is not universal translation invariance. The origin of the pooling grid still matters. Compare the two actual maps with common color limits, then inspect a particular window directly. Understanding this reduction prepares you to track how a CNN trades spatial detail for a smaller representation before its final classifier.

Try it

  1. Apply max and average pooling with two-by-two windows and stride two.
  2. Display both results with identical value limits.
  3. Check one cell against the corresponding input window.
Python · run in order
gray_batch = image.mean(axis=-1, keepdims=True)[None, ...]
max_map = keras.layers.MaxPooling2D(2, strides=2)(gray_batch).numpy()
mean_map = keras.layers.AveragePooling2D(2, strides=2)(gray_batch).numpy()
fig, axes = plt.subplots(1, 2, figsize=(7, 3))
for ax, values, title in zip(axes, [max_map, mean_map], ['Max pooling', 'Average pooling']):
    ax.imshow(values[0, :, :, 0], cmap='gray', vmin=0, vmax=1)
    ax.set_title(title)
fig.tight_layout()

Read the result

Both outputs have the same shape but can differ at windows containing mixed brightness. Neither summary preserves every original pixel or its precise position within a pooled cell.

Change and compare

  • Find a window where the two summaries agree.
  • Construct two different two-by-two patches with the same maximum.
