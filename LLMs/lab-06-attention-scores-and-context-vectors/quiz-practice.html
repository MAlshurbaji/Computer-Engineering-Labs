Attention Scores and Context Vectors

MaterialPracticeQuiz

Choose one answer for questions 1–6. Write Python code for questions 7–8.

1. A query [2.,-1.] is compared with source vectors [1.,3.] and [-2.,0.]. Which score vector results from dot products in that source order?

  1. [1.,4.]
  2. [-1.,-4.]
  3. [5.,-2.]
  4. [2.,-2.]

2. A query's three source scores are [4.,1.,-2.]. Which replacement must give the same softmax weights, up to rounding?

  1. [14.,11.,8.]
  2. [8.,2.,-4.]
  3. [4.,4.,4.]
  4. [1.,4.,-2.]

3. Weights [0.75,0.25] mix source vectors [2.,0.] and [0.,8.]. What context vector is produced?

  1. [2.,8.]
  2. [2.,6.]
  3. [0.75,0.25]
  4. [1.5,2.]

4. An attention matrix has queries on rows and source positions on columns. After softmax is accidentally applied down columns, every column sums to one but query-row sums differ. What does this reveal?

  1. Matrix multiplication always requires column-normalized weights.
  2. The source features must all be negative.
  3. Normalization was performed across queries rather than across each query's sources.
  4. The model has learned a vocabulary distribution.

5. A context uses weights [0.4,0.6] and two identical source vectors [3.,-2.]. The weights change to [0.1,0.9] while those vectors stay fixed. What happens to the context?

  1. It must change because every weight changed.
  2. It becomes zero because the source rows repeat.
  3. It becomes the second weight vector.
  4. It stays [3.,-2.].

6. In a handcrafted attention display, one source position has the largest weight. Which conclusion is supported by that display alone?

  1. Removing that source would leave every other weight unchanged.
  2. Its source vector has the largest scalar coefficient in this query's weighted sum.
  3. The sentence is factually correct.
  4. The token at that position is the correct next word.
