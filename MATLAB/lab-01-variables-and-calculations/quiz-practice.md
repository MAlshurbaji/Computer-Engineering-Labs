# MATLAB — Lab 01: Practice Quiz

Choose one answer for each MCQ.

## 1. MCQ

A 2.5 L container is poured into cups measured in mL. Which expression first converts the container volume into mL?

A. `2.5 * 1000`

B. `2.5 / 1000`

C. `2.5 + 1000`

D. `1000 / 2.5`

## 2. MCQ

A script runs `x = 6; saved = x; x = 9; difference = x - saved;`. What is `difference`?

A. 0

B. 3

C. 6

D. 9

## 3. MCQ

A trip has one 11-minute check-in and four rides of 7 minutes each. Which expression matches that description?

A. `4 * (11 + 7)`

B. `(11 + 4) * 7`

C. `11 + 4 * 7`

D. `11 * 4 + 7`

## 4. MCQ

Twenty-one identical candles fit into cartons holding four each. Which expression gives the fewest cartons that can contain all candles?

A. `floor(21/4)`

B. `mod(21,4)`

C. `21/4`

D. `ceil(21/4)`

## 5. MCQ

After `value = 7/6; text = sprintf('%.1f', value);`, which statement is true?

A. `value` still stores the division result; `text` contains a one-decimal representation.

B. Both `value` and `text` become the numeric value 1.2.

C. `value` becomes 1 and `text` becomes 2.

D. `sprintf` changes `value` but does not create `text`.

## 6. MCQ

A square coaster has side length `s` centimetres. Which expression calculates its diagonal in centimetres?

A. `sqrt(2*s)`

B. `sqrt(s^2 + s^2)`

C. `2*s^2`

D. `s/2`

## 7. Coding

A small cart wheel has radius 0.08 m and rolls 37 m without slipping. Write a standalone script that calculates circumferenceMetres using pi, turnsRequired as a possibly fractional count, completeTurns as a whole count, and remainingMetres after those complete turns. Display the turn count to two decimal places and the remaining distance to three decimal places, with labels. Keep the unrounded values for the calculations.

## 8. Coding

A playlist contains six videos, each 3.25 minutes long, with exactly five 15-second pauses between them. Write a standalone script that calculates totalSeconds, wholeMinutes, and leftoverSeconds. Display the total as labelled whole minutes and seconds. Declare the video and pause inputs separately and do not round individual video durations.
