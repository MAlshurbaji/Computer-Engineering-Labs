# Lab 01 · Syntax and Semantics in Python: Practice Quiz

Write a Python code block for each task. The given variables already exist. Do not use `input()` or `print()`.

## 1. Laundry pickup record

Given:

- `pickup_code`: a string containing exactly four digits, possibly beginning with zeros.
- `item_count_text`: a string of one to three digits representing a quantity from 0 to 99. It may also begin with zeros.

Store the pickup code in `receipt_code` as a string, preserving every digit. Store the quantity in `items_ready` as an integer. Leave both given variables unchanged.

## 2. Edit a calendar reminder

Given:

- `reminder_text`: the current reminder, a nonempty string.
- `replacement_text`: the new reminder, a nonempty string.
- `last_error`: an earlier error message stored as a string, or `None`.

After your code runs:

- `undo_text` must contain the original reminder as a string.
- `reminder_text` must contain the replacement text as a string.
- `last_error` must be `None`.

Leave `replacement_text` unchanged.
