# Lab 08 · Practice Quiz

## 1. Shared folder label

Define `shared_start(first, second)`. Return the longest text that appears at the beginning of both folder labels, matching case exactly. Return an empty string if their first characters differ or either label is empty. Call it with the supplied `first` and `second`; store the result in `shared`. Do not use `input()` or `print()`.

## 2. Repeated chat words

Define `repeated_word(message)`. Return `True` if two adjacent words are the same after converting them to lowercase; otherwise return `False`. Split words at whitespace and keep punctuation as part of each word. Empty and single-word messages return `False`. Call it with the supplied `message`; store the result in `needs_edit`. Do not use `input()` or `print()`.
