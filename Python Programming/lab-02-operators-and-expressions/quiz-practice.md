# Python Programming

## Lab 02 · Operators and Expressions: Practice Quiz

Write one Python code block for each task. The given variables already exist. Do not use `input()` or `print()`.

### 1. Double-sided handouts

Given integer `pages` from 0 to 500 and positive integer `sheets_per_pack`, each sheet holds at most two pages. Store:

- `sheets_needed`: the smallest whole number of sheets that can hold all pages;
- `full_packs`: the number of completely filled packs of those sheets;
- `loose_sheets`: the sheets left outside complete packs.

Use arithmetic expressions only. Leave the given variables unchanged.

### 2. Quiet music

Given Boolean variables `paused` and `headphones`, and integer `volume` from 0 to 100, store a Boolean in `can_play`. Music may play only when it is not paused and either headphones are connected or the volume is at most 20.

Use a single assignment with logical and comparison operators. Leave all given variables unchanged.
