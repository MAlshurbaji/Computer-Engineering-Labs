# Lab 07 · Practice Quiz

## 1. Consecutive shopping duplicates

Define `tidy_list(items)`. Return a new list that keeps only one item from each consecutive run of equal shopping entries. Equal entries separated by another item stay. Preserve order and leave `items` unchanged. Call it with the supplied `items` and store the result in `tidied`. An empty list returns an empty list. Do not use `input()` or `print()`.

## 2. Cinema groups

Define `fit_groups(groups, seats)`. Process the list of positive group sizes in order. Accept a whole group only when enough seats remain; skip groups that do not fit and continue checking later groups. Return a new list of accepted group sizes. Do not change `groups`. `seats` is a nonnegative integer. Call the function with the supplied variables and store the result in `accepted`. Do not use `input()` or `print()`.
