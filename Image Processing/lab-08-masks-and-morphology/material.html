Masks and Morphology

MaterialPracticeQuiz

Turn a shaded shopping note into explicit foreground decisions and inspect what cleanup changes. You will keep the original colors available while testing masks that can also remove useful small details.

Python · shared setup
import cv2
import numpy as np
import matplotlib.pyplot as plt
from PIL import Image, ImageDraw
cv2.setNumThreads(1)
rng = np.random.default_rng(208)
# A shaded paper sheet with printed words, button shapes and a small punctuation dot.
h, w = 128, 160
yy, xx = np.mgrid[:h, :w]
ink_canvas = Image.new('L', (w, h), 0)
draw = ImageDraw.Draw(ink_canvas)
draw.text((17, 18), 'SHOPPING', fill=255)
draw.text((18, 40), 'tea  bread', fill=255)
draw.text((18, 56), 'rice  milk', fill=255)
draw.ellipse((22, 81, 48, 108), fill=255)
draw.ellipse((70, 81, 96, 108), fill=255)
draw.rectangle((114, 82, 140, 107), fill=255)
draw.rectangle((147, 53, 148, 54), fill=255)
ink_truth = (np.asarray(ink_canvas) > 0).astype('uint8') * 255
illumination = 76 + 155 * xx / (w - 1)
paper = illumination + 1.4 * np.sin(yy * 1.1) + rng.normal(0, 0.7, (h, w))
paper[ink_truth != 0] *= 0.28
gray_sheet = np.clip(np.rint(paper), 0, 255).astype('uint8')
sheet_rgb = np.stack([gray_sheet, gray_sheet, np.clip(gray_sheet.astype('int16') - 5, 0, 255).astype('uint8')], axis=2)
# Independent binary button fixture: foreground is 255, background is zero.
button_canvas = Image.new('L', (w, h), 0)
draw = ImageDraw.Draw(button_canvas)
draw.ellipse((24, 34, 64, 76), fill=255)
draw.ellipse((68, 34, 108, 76), fill=255)
draw.rectangle((38, 91, 102, 113), fill=255)
draw.rectangle((137, 98, 138, 99), fill=255)
button_mask = np.asarray(button_canvas).copy()

Guided task 01

Global threshold and foreground meaning

A binary mask records membership in a selected region. Here dark printed marks are the intended foreground, so an inverse threshold makes low grayscale values white in the mask. OpenCV’s THRESH_BINARY_INV includes values equal to the threshold: a value at or below ninety becomes 255, and a larger value becomes zero. Define this boundary explicitly instead of relying on the apparent brightness of the display.

The drawn sheet has a gradual illumination change. A single global cutoff can select dark background on the shaded side even when the ink itself is correctly included. That failure is visible because the original drawing supplies an exact ink mask, which is available only in this controlled example. An actual paper image would not ordinarily arrive with perfect reference membership. Inspect the mask over the whole sheet, including corners and spaces between words, rather than judging only one correctly selected letter. The reference mask represents the drawing operation, not a claim that every selected pixel will help a later CNN. Keep the original RGB array and its coordinates intact while experimenting with selection rules.

Try it

  1. Apply inverse binary threshold ninety to the supplied grayscale sheet.
  2. Display the original sheet, resulting mask and known drawn-ink reference.
  3. Compare selected background areas as well as the letters.
Python · run in order
threshold_used, global_mask = cv2.threshold(gray_sheet, 90, 255, cv2.THRESH_BINARY_INV)
fig, axes = plt.subplots(1, 3, figsize=(12, 3.5))
axes[0].imshow(sheet_rgb)
axes[0].set_title('Shaded paper')
axes[0].axis('off')
axes[1].imshow(global_mask, cmap='gray', vmin=0, vmax=255)
axes[1].set_title('Global inverse threshold')
axes[1].axis('off')
axes[2].imshow(ink_truth, cmap='gray', vmin=0, vmax=255)
axes[2].set_title('Known drawn ink')
axes[2].axis('off')
fig.tight_layout()

Read the result

Guided task 02

Adaptive thresholds use local context

An adaptive threshold changes its cutoff with the surrounding image. The Gaussian option uses a locally weighted average and subtracts the constant C. With an inverse binary decision, sufficiently dark pixels relative to that local context become foreground. The neighborhood width must be odd and greater than one; this example uses twenty-one pixels and C equal to seven intensity counts on the zero-to-255 scale.

Local adaptation can respond to a slow illumination gradient, but it is not a general object detector. A neighborhood much smaller than a broad dark object can treat that object’s interior as locally ordinary and retain only some boundaries. Fine paper texture can also become foreground if the settings are too sensitive. Compare words and filled button shapes separately because their spatial structures differ. OpenCV adaptiveThreshold expects an eight-bit single-channel source, so do not feed the RGB array or standardized floating input directly into this call. The global and adaptive masks are alternative selection rules; neither establishes a universally better preprocessing choice. Record the window and offset, and select settings using appropriate development data rather than inspecting a held-out test set repeatedly.

Try it

  1. Use the grayscale uint8 sheet and a Gaussian adaptive threshold.
  2. Set maximum value 255, inverse binary mode, block size twenty-one and C seven.
  3. Compare the full masks and a matched crop around the writing.
Python · run in order
adaptive_mask = cv2.adaptiveThreshold(gray_sheet, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY_INV, 21, 7)
fig, axes = plt.subplots(1, 4, figsize=(16, 3.5))

Guided task 03

Binary storage and applying a mask

A boolean selection and a uint8 mask can describe the same spatial membership while using different stored values. In this lesson boolean True corresponds to selected foreground, and the OpenCV mask stores that membership as 255. Keep the distinction visible: multiplying a uint8 RGB array by a zero-or-255 mask is not the same operation as retaining selected pixels and setting others to black.

The mask argument of bitwise_and uses nonzero entries to decide where output is written. With the image supplied as both operands and a newly allocated result, selected pixels retain their RGB values and unselected pixels become zero. This call does not change RGB to BGR and does not reposition pixels. A boolean array can express the same operation using NumPy selection with a channel axis added for broadcasting. Check both implementations for exact equality. The black background is a deliberate output policy rather than evidence that the scene originally contained black material. A later model might learn this masking boundary or background choice, so preserve the full image as a comparison and record how the mask was made.

Try it

  1. Convert the adaptive mask to a boolean selected array.
  2. Apply it with OpenCV and with NumPy broadcasting.
  3. Compare the results and confirm that retained colors are unchanged.
Python · run in order
selected = adaptive_mask != 0
masked_rgb = cv2.bitwise_and(sheet_rgb, sheet_rgb, mask=adaptive_mask)
numpy_masked = np.where(selected[..., None], sheet_rgb, 0).astype('uint8')
fig, axes = plt.subplots(1, 4, figsize=(16, 3.5))
axes[0].imshow(sheet_rgb)
axes[0].set_title('Original RGB')
axes[0].axis('off')
axes[1].imshow(adaptive_mask, cmap='gray', vmin=0, vmax=255)
axes[1].set_title('Spatial mask')
axes[1].axis('off')
axes[2].imshow(masked_rgb)
axes[2].set_title('Selected RGB')
axes[2].axis('off')
axes[3].imshow(numpy_masked)
axes[3].set_title('Equivalent NumPy result')
axes[3].axis('off')
fig.tight_layout()

Read the result

The output is still a three-channel RGB image. At selected coordinates all three original channel values remain intact; excluded coordinates use the stated black background.

  • Check what happens conceptually if image and mask come from different crop locations.

Guided task 04

Erosion and dilation change foreground geometry

Morphology operates on the shape of foreground regions through a structuring element. For a flat three-by-three square on a binary mask, erosion keeps a foreground center only when the entire neighborhood is foreground. Dilation selects a center when any covered location is foreground. Their effects depend on which value you declared to be foreground: changing the black-white interpretation changes the meaning of shrinking and growing.

Use the independent button mask so intensity threshold errors do not obscure the geometry. The small square at the lower right represents a legitimate tiny mark, not simulated noise. Erosion can remove it even though it belongs to the intended selection. This task explicitly supplies zero outside the image boundary, corresponding to background. Border assumptions matter when an object touches the frame; a different default or padding convention can change those edge results. Kernel shape also matters: a square includes diagonal neighbors, while a cross treats the immediate neighborhood differently. Morphological changes are geometric choices, not automatic improvements in the correctness of a mask or the performance of a future recognition system.

Try it

  1. Create a three-by-three square uint8 structuring element.
  2. Erode and dilate the same button mask using one iteration and zero outside the frame.
  3. Inspect both the large shapes and the legitimate tiny mark.
Python · run in order
square3 = np.ones((3, 3), dtype='uint8')
eroded = cv2.erode(button_mask, square3, iterations=1, borderType=cv2.BORDER_CONSTANT, borderValue=0)
dilated = cv2.dilate(button_mask, square3, iterations=1, borderType=cv2.BORDER_CONSTANT, borderValue=0)
fig, axes = plt.subplots(1, 3, figsize=(12, 3.5))
axes[0].imshow(button_mask, cmap='gray', vmin=0, vmax=255)
axes[0].set_title('Original foreground')
axes[0].axis('off')
axes[1].imshow(eroded, cmap='gray', vmin=0, vmax=255)
axes[1].set_title('Eroded foreground')
axes[1].axis('off')
axes[2].imshow(dilated, cmap='gray', vmin=0, vmax=255)
axes[2].set_title('Dilated foreground')
axes[2].axis('off')
fig.tight_layout()

Read the result

The small mark can disappear during erosion while nearby foreground regions can approach one another during dilation. Neither change identifies the meaning of the region.

Change and compare

  • Repeat with cv2.getStructuringElement(cv2.MORPH_CROSS, (3, 3)).
  • Move a shape to the frame edge and keep the zero-border rule explicit.

Guided task 05

Opening removes unsupported small structures

Opening applies erosion followed by dilation with the same structuring element. The second operation regrows surviving regions, but it cannot restore every feature removed by the first operation. Tiny disconnected specks, thin bridges and narrow protrusions may disappear. Larger corners can also change, so opening is not an exact operation that removes only accidental noise and leaves all intended shapes untouched.

Add a few known one-pixel defects to the button mask. They let us distinguish the intended experimental disturbance from the legitimate two-by-two mark already present in the fixture. Both are too small to survive this three-by-three opening. The output therefore illustrates a useful cleanup effect and an unwanted semantic loss in the same image. A numerical reduction in component count would not tell those cases apart. Compare the original intended mask, the disturbed mask and the processed result, and explicitly inspect the small legitimate mark. In practical preparation for a CNN, tiny targets or printed punctuation might carry the class information. That decision requires knowledge of the task and independent evaluation; the filter itself has no such knowledge.

Try it

  1. Add three stated isolated one-pixel specks to a copy of the button mask.
  2. Apply one three-by-three square opening with zero background outside.
  3. Check the added defects and the original tiny mark separately.
Python · run in order
speckled = button_mask.copy()
speckled[15, 15] = 255
speckled[15, 135] = 255
speckled[115, 15] = 255
opened = cv2.morphologyEx(speckled, cv2.MORPH_OPEN, square3, borderType=cv2.BORDER_CONSTANT, borderValue=0)
fig, axes = plt.subplots(1, 3, figsize=(12, 3.5))
axes[0].imshow(button_mask, cmap='gray', vmin=0, vmax=255)
axes[0].set_title('Intended mask')
axes[0].axis('off')
axes[1].imshow(speckled, cmap='gray', vmin=0, vmax=255)
axes[1].set_title('Added isolated specks')
axes[1].axis('off')
axes[2].imshow(opened, cmap='gray', vmin=0, vmax=255)
axes[2].set_title('Opening result')
axes[2].axis('off')
fig.tight_layout()

Read the result

The added specks disappear, but so does the intended tiny mark. A cleaner-looking result can remove exactly the feature a later task needs.

  • Use a larger kernel and list additional intended structures it removes.

Guided task 06

Closing can fill gaps and merge objects

Closing reverses the order: dilation is followed by erosion using the same structuring element. It can fill small background holes and narrow gaps within foreground regions. That behavior can repair a broken mask, but it can also join two objects that should remain separate. The operation does not know whether a gap is accidental damage or a meaningful separation.

The two large circular regions in the button fixture are close together. This experiment adds two small background holes inside them and uses a five-by-five square. Compare the holes and the gap between the circles as separate questions. Even when a hole disappears as intended, the count or connectivity of objects may change elsewhere. Keep the zero-border policy explicit; closing near an image edge can behave differently from closing an isolated shape well inside the frame. Opening and closing also do not generally commute: exchanging their order creates a different processing pipeline. Record both the kernel and sequence when documenting preprocessing, and keep a reference image so later changes can be audited without guessing which operation altered a particular feature.

Try it

  1. Cut two supplied two-by-two background holes inside the button regions.
  2. Close the damaged mask with a five-by-five square and zero exterior background.
  3. Inspect hole filling and the separation between neighboring buttons.

holed = button_mask.copy()

Guided task 07

Connected components and explicit area rules

Connected-component labeling groups touching foreground pixels. Four-connectivity uses horizontal and vertical neighbors; eight-connectivity also joins diagonal contacts. The choice changes which pixels belong to the same component and must be stated before interpreting a component count. Label zero represents background, so the total number of returned labels includes one label that is not a foreground object.

Here an eight-connected analysis is applied to the speckled button mask. OpenCV returns a label image and statistics including each region’s area in pixels. The example keeps foreground components with at least twenty pixels. That is an explicit size policy for this experiment, not a learned definition of a button. The small legitimate mark and the artificial specks can both be rejected. Component identifiers are temporary analysis results rather than class labels; their numeric order has no semantic meaning. The color map is only a visualization of these IDs. When creating a kept mask, force the background label to remain excluded even if its area is large enough to pass the numerical cutoff. Otherwise the largest background region could become selected by mistake.

Try it

  1. Label the speckled mask using eight-connectivity.
  2. Keep non-background labels with area at least twenty pixels.
  3. Display label colors and the selected mask alongside the input.
Python · run in order
label_count, labels, stats, centers = cv2.connectedComponentsWithStats(speckled, connectivity=8)
keep_label = stats[:, cv2.CC_STAT_AREA] >= 20
keep_label[0] = False
area_mask = (keep_label[labels].astype('uint8') * 255)
palette = np.random.default_rng(870).integers(40, 256, (label_count, 3), dtype='uint8')
palette[0] = 0
label_rgb = palette[labels]
print('Foreground components:', label_count - 1, 'retained:', np.count_nonzero(keep_label))
fig, axes = plt.subplots(1, 3, figsize=(12, 3.5))
axes[0].imshow(speckled, cmap='gray', vmin=0, vmax=255)
axes[0].set_title('Component input')
axes[0].axis('off')
axes[1].imshow(label_rgb)
axes[1].set_title('Temporary label colors')
axes[1].axis('off')
axes[2].imshow(area_mask, cmap='gray', vmin=0, vmax=255)
axes[2].set_title('Area at least 20')
axes[2].axis('off')
fig.tight_layout()

Read the result

Label colors show grouping, not categories or confidence. Compare each rejected region with the known fixture before deciding whether the area rule is appropriate.

  • Lower the area cutoff enough to retain the intended two-by-two mark.

Guided task 08

Aligned masks and cleanup limits

A spatial mask is meaningful only when each mask coordinate refers to the same image coordinate. Matching height and width is necessary but insufficient: a shifted or differently cropped mask can have the correct shape and still select the wrong content. This task uses the exact drawn-ink mask and the original RGB sheet, so the coordinate relationship is known without estimation.

Apply a three-by-three opening to the ink mask, then produce masked RGB images before and after that cleanup. The full sheet includes letters and a small punctuation mark whose strokes can be narrower than the structuring element. The comparison makes the cost of the operation visible in the actual retained image rather than only as a count of foreground pixels. Preserve the untouched RGB array and record the mask rule separately. If a pipeline later resizes an image and categorical mask, both need the same geometry and the mask needs nearest-neighbor interpolation to avoid inventing intermediate labels. That is a coordinated transformation task, not permission to process the mask independently. A future model comparison should retain a full-image baseline and independent evaluation data; cleaner binary geometry alone cannot establish better recognition.

Try it

  1. Open the known drawn-ink mask with the supplied three-by-three square.
  2. Apply the original and cleaned masks to the same unchanged RGB sheet.
  3. Inspect which printed details remain in each retained-color result.
Python · run in order
cleaned_ink = cv2.morphologyEx(ink_truth, cv2.MORPH_OPEN, square3, borderType=cv2.BORDER_CONSTANT, borderValue=0)
ink_rgb = np.where((ink_truth != 0)[..., None], sheet_rgb, 255).astype('uint8')
cleaned_ink_rgb = np.where((cleaned_ink != 0)[..., None], sheet_rgb, 255).astype('uint8')
