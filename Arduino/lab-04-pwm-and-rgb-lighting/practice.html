Rounding and a Fixed Command Budget

Activity 6 · Build it yourself

Split a warm-light command budget

Use the M2 common-cathode circuit and pot. Start all channels off. Let totalDuty=floor(raw×150/1023) using wide arithmetic. Assign green the integer part of totalDuty/3 and red all remaining units so red+green equals totalDuty exactly. Blue stays 0. Read once, write all channels, and delay 20 ms. This is a command budget, not a brightness guarantee.
