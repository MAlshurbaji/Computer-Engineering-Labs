Question 6 · Coding

Use manual scanning with inactive rows INPUT, one selected row OUTPUT LOW, and columns INPUT_PULLUP. Accept one event after a single key is unchanged for 25 ms; require all keys released for 25 ms before the first or next event. Reject scans containing multiple keys and require that release again. Write a complete sketch with no pending choice at startup. Accepted keys 1–3 replace the pending digit and restart a 5000 ms timer. # prints ORDER, one space and that digit, then clears it; with no choice, print EMPTY. At 5000 ms elapsed, clear a pending choice and print TIMEOUT once. Process expiration before that loop’s key event, including at equality.
