Derived Whole-Unit Settings

Activity 6 · Build it yourself

Choose a marked craft-strip length

Write a standalone A0-pot sketch at 9600 baud. Define mark = 5 + floor(raw × 20 / 1023) using safe long arithmetic. Each mark represents 2 cm, so length_cm is twice that whole mark. Print mark=number length_cm=number on one line, using one stored sample, then delay 200 ms. Quantize the mark before calculating length; no cutter is connected.
