Question 5 · Coding

Write a standalone movement reporter for HC-SR04: VCC to 5V, GND to GND, TRIG D7, ECHO D8 on Uno R3. Use a 10 microsecond trigger, pulseIn timeout 25000 microseconds, at least 100 ms between trigger starts, and cm = us / 58.0. Accept only nonzero echoes giving 2–400 cm inclusive. Compare each valid distance with the immediately preceding valid reading only when no invalid reading intervened. Print MOVED at 9600 baud if the absolute change is at least 10 cm; then retain the newest valid distance as baseline. On invalid data print INVALID and clear the baseline. Startup has no baseline.

Question 6 · Coding

Using the HC-SR04 wiring and acquisition limits shown, write a standalone sensor-status monitor. Print WAITING once at startup at 9600 baud. A valid reading immediately selects OK and resets the consecutive-invalid count. Three consecutive invalid readings select CHECK SENSOR; the first two preserve the current status. Print a status only when it changes. Cap the count at three so it cannot overflow. Use no long delay and do not print distance values.

Responses are not saved automatically; print to keep a copy.
