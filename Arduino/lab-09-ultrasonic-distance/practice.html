Independent rearming and events

Activity 5 · Build it yourself

Count book placements

Write a complete sketch using the standard HC-SR04 wiring and helper limits. Start count 0 and disarmed. A valid distance strictly above 22 cm arms; a later valid distance strictly below 15 cm counts one placement and disarms. Equality or the middle band retains armed state. Invalid prints INVALID and disarms. Print counts only on a placement at 9600 baud. Keep starts at least 100 ms apart and no long delay.

Independent fixed-window policy

Activity 6 · Build it yourself

Require coverage before reporting a window mean

Use the standard sensor wiring, 10 us trigger, 25000 us timeout, 2..400 cm validity and 100 ms minimum spacing. Start counters and sum at 0. For each six acquisition attempts, print validCount followed by the one-decimal mean of valid distances only if at least four attempts were valid; otherwise print INSUFFICIENT after the count. Invalid attempts occupy slots but add no distance. Reset all statistics after each window and use 9600 baud.
