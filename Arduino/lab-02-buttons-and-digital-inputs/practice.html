Conflicting Requests

Activity 6 · Build it yourself

Show a single requested direction

D2 requests left and D3 requests right; both are INPUT_PULLUP buttons to ground. Use separately resisted LEDs D8 for left and D9 for right, initially off. After every decision, light the corresponding LED only for a single held request. Both held is a conflict and must clear both; neither also clears both. Read each input once per pass and use no remembered state or delay.
