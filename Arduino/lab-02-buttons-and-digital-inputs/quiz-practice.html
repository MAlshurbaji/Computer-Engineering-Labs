Question 5 · Coding

Write a complete sketch for a model with two window buttons. D2 and D3 use INPUT_PULLUP; a held button represents an open window. Use D8 for any window open and D9 for both windows closed, with separate 330 ohm LED branches as shown. Start both LEDs off in setup. After each loop decision, exactly one indicator must be on: D8 if either or both buttons are held, otherwise D9. Read both inputs each pass and use no delay or remembered state.

Question 6 · Coding

Write a complete sketch for two current meal requests. D2 and D3 are INPUT_PULLUP buttons to GND. A held button means that person currently requests a meal. Start the D8 and D9 LEDs off. After each loop decision, light D8 alone for exactly one request, D9 alone for two requests, or neither for no requests. Do not count past presses, toggle states, or add a delay. Read both inputs once per pass.

Responses are not saved automatically; print to keep a copy.
