Independent batch control

Activity 5 · Build it yourself

Smooth a slowly changing shelf light

Reuse teaching task 2 wiring. Write a complete sketch with your measured shade/bright pair (illustrative 240/780), span>=80 validation, and one-third/two-thirds hysteresis. Start D9 OFF. Sample every 40 ms, update and print only after six real non-overlapping readings. Reset each batch. Invalid calibration prints CALIBRATION INVALID once at 9600 baud and stays off. Use unsigned timing and no delay.

Independent consecutive evidence

Activity 6 · Build it yourself

Require sustained shade before lighting

Reuse teaching task 2 wiring. Start D9 OFF. Sample A0 every 100 ms without delay. Three consecutive readings <=350 turn ON; any reading >350 resets that consecutive counter. One reading >=650 turns OFF. Otherwise retain the lamp state. Saturate the counter at 3. Use these supplied exercise thresholds, which are not universal light levels; unsigned timing must work across rollover.
