Pause and Resume State

Activity 5 · Build it yourself

A pauseable desk reminder

Reuse D2, D9, and built-in LED from M1. Use M2 debounce 30 ms and held-at-start behavior. Start running with D9 on, built-in off. While running, toggle built-in every 400 ms. Each accepted press changes running/paused. Pause forces both off. Resume sets D9 on, built-in off, and begins a fresh 400 ms wait. Process mode changes before the due toggle. Use unsigned elapsed checks and no delay.

Restartable Delayed Actions

Activity 6 · Build it yourself

Delay a desk-ready signal after the last request

Use D2 INPUT_PULLUP to GND and the resisted D9 LED. Adopt the startup input without an event; use 30 ms stable-level debounce. D9 starts off with no pending request. Every fresh accepted press turns it off and starts or restarts a1500 ms wait. After that wait, turn D9 on and keep it on until another accepted press. Process presses before due completion, so a simultaneous new press restarts the wait. No delay; holds do not restart it.
