Question 5 · Coding

Write a standalone desk temperature-range recorder for the TMP36 circuit shown. Use DEFAULT reference, assume 5.0 V, and compute C = (raw × 5.0 / 1024 − 0.500) / 0.010. Sample A0 every 500 ms without delay. Accept −40–125 C inclusive. The first valid estimate initializes both stored minimum and maximum; later valid estimates update them. After each valid sample, print low_C=minimum high_C=maximum on one line at 9600 baud, each to one decimal place. On invalid data print CHECK and keep any earlier extrema unchanged. Before the first valid sample, do not invent extrema or print a range.

Question 6 · Coding

Write a standalone adjustable desk-temperature indicator. Use the shown TMP36 on A0, a 10k pot wiper on A1, and a D5 LED. Start D5 off and Serial at 9600 baud. Every 500 ms without delay, read both inputs once. With DEFAULT and nominal 5.0 V, compute C = (raw × 5.0 / 1024 − 0.500) / 0.010; accept −40–125 C inclusive. Set the whole-degree target to 18 + floor(potRaw × 12 / 1023), using safe Uno arithmetic. For valid temperature, D5 is on at or above the target and off below it; print C=temperature target_C=target on one line, temperature to one decimal place. For invalid data, turn D5 off and print CHECK. This LED is an indicator, not a heater control.

Responses are not saved automatically; print to keep a copy.
