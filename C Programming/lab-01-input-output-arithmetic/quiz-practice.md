# C Programming - Foundations in Computer Science

## Lab 01 · Input, Output, and Arithmetic: Practice Quiz

Write a complete C program for each task. Assume valid input unless the task asks you to handle invalid values.

### 1. Photo-card capacity

Read free storage in whole KB (0–100000) and the size of one photo in KB (1–10000). Print the number of complete photos that fit, then unused KB, on separate lines. Every photo has the stated size. Print no prompts.

### 2. Refill purchase

Read the empty container mass, filled container mass, and refill price per kilogram as decimal numbers. Masses are in grams; the filled mass is at least the empty mass. Each mass is 0–5000 and the price is 0–100 AED/kg. Print the refill mass in grams, then its cost in AED, each to two decimal places on separate lines. Print no prompts.
