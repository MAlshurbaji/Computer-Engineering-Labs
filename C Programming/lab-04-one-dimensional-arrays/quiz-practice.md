# C Programming - Foundations in Computer Science

## Lab 04 · One-Dimensional Arrays: Practice Quiz

Write a complete C program for each task. Assume valid input unless the task asks you to handle invalid values.

### 1. Repeated shopping entry

Read an entry count n (1–8), then n shopping-item codes (integers 1–99) into an array. Find two positions containing the same code. Choose the pair whose later position comes first in the list; if needed, choose the earliest earlier position. Print the two one-based positions, earlier then later, on one line. Print `None` if every code is different. Print no prompts. For codes `4 8 8 4`, print `2 3`.

### 2. Largest screen-brightness jump

Read six brightness settings (integers 0–100) into an array. Find the largest absolute change between consecutive settings. Print that change, then the one-based position of the later setting in that pair, on separate lines. Ties choose the earliest pair; unchanged neighbours have a change of zero. Print no prompts.
