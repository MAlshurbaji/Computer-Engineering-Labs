# C Programming - Foundations in Computer Science

## Lab 03 · Switch Statements and Loops: Practice Quiz

Write a complete C program for each task. Assume valid input unless the task asks you to handle invalid values.

### 1. Read until the phone is charged

Read a starting battery percentage (0–100), followed by positive integer charging increases (1–100). Stop reading increases once the battery reaches or passes 100; cap the final battery at 100. If it starts at 100, read no increases. Print the number of increases used, then the final percentage, on separate lines. Enough increases are supplied. Print no prompts.

### 2. Daily shop checks

Read a day count (1–5). For each day, read exactly four delivery status codes: 0 means absent, 1 means waiting, and 2 means collected. Print the number collected that day on its own line, followed after all days by the word `Done`. Print no prompts. Keep daily counts separate.

### 3. Reusable-cup desk

The desk starts with 5 cups. Read character commands until X: T takes one cup if any remain, R returns one cup, and any other character leaves the count unchanged. No more than 20 commands are supplied before X. Use a switch statement. Print only the final cup count; do not print a message for individual commands.
