# C Programming - Foundations in Computer Science

## Lab 05 · Two-Dimensional Arrays: Practice Quiz

Write a complete C program for each task. Assume valid input unless the task asks you to handle invalid values.

### 1. Rotate a tiny picture

Read six brightness values (integers 0–255) in row order for a picture with two rows and three columns. Store the picture in a 2D array. Rotate it 90 degrees clockwise into a second 2D array. Print the rotated picture as three rows of two values, separated by single spaces. Print no prompts. For input rows `1 2 3` and `4 5 6`, the output rows are `4 1`, `5 2`, and `6 3`.

### 2. Lower electricity use

Read a 2×3 before table followed by a 2×3 after table, both in row order. Rows are two homes; columns are the same three days. Entries are whole kWh from 0 to 100. A day qualifies if neither home used more electricity afterwards and at least one used less. Print qualifying one-based day numbers in increasing order, one per line; print `None` if no day qualifies. Store both tables in 2D arrays and print no prompts.
