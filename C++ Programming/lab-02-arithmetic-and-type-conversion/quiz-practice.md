# Lab 02 · Practice Quiz

## 1. Kitchen timer finish time

Write a complete C++ program. Read a starting hour (0–23), starting minute (0–59), and timer duration (0–1439 minutes), all integers. Print the hour and minute when the timer finishes, using a 24-hour clock and wrapping past midnight. Separate them with one space; leading zeroes are not required. Use arithmetic only, without conditions or loops. Print no prompts.

## 2. Stackable storage boxes

Write a complete C++ program. Read the number of identical storage boxes (1–20), the height of one box (10–50 cm), and how far each additional box sits inside the box below it (0–9 cm). All inputs are integers. The bottom box contributes its full height. Print the total stack height in centimetres on one line and in metres on the next, retaining fractional metres. Use arithmetic only. Print no prompts.

## 3. Scan a page interval

Write a complete C++ program. An album has consecutively numbered pages beginning at 1. Each scan contains the same number of consecutive pages: scan 1 starts at page 1, scan 2 starts immediately after scan 1, and so on. Read the first wanted page (1–1000), how many pages are wanted (1–1000), and pages per scan (1–8). Print how many scans contain at least one wanted page. For first page 4, count 3, and 4 pages per scan, the result is 2. Use arithmetic only. Print no prompts.
