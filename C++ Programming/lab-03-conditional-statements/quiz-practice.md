# C++ Programming

## Lab 03 · Conditional Statements: Practice Quiz

Write a complete C++ program for each task.

### 1. Change a seat request

Read the first person’s seat, the second person’s seat, and the seat requested by the first person. All are integers 1–50; the two starting seats are distinct. If the requested seat is already the first person’s, leave both unchanged. If it belongs to the second person, swap their seats. Otherwise move only the first person to the requested seat. Print the final first and second seat numbers on one line, separated by a space. Print no prompts.

### 2. A timer across midnight

Read a timer’s start hour, start minute, end hour, and end minute. Hours are 0–23 and minutes are 0–59. The end is the next occurrence of that clock time after the start, except identical start and end times mean zero elapsed minutes. Print only the elapsed whole minutes.

### 3. The next bookmark

Read the current page and two bookmarked page numbers, all integers 1–500. A usable bookmark must be strictly after the current page. Print the smallest usable bookmarked page; duplicate bookmarks count as the same destination. Print `No later bookmark` if neither is usable. Print no prompts.
