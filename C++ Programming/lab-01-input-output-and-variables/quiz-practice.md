# Lab 01 · Practice Quiz

## 1. Move storage boxes

Write a complete C++ program. Read the box counts on shelves A and B, then the number moved from A to B. All three are integers from 0 to 100, and the moved count does not exceed A’s count. Print the two counts after the move, A first, separated by one space. Print no prompts.

## 2. Boat tickets

Write a complete C++ program. Read a boarding-zone letter A–Z, the number of adult tickets, and the number of child tickets. Both counts are integers from 0 to 40. Adult tickets cost 12 AED each and child tickets cost 5 AED each. Print the zone on the first line and the total cost in whole AED on the second. Print no prompts.

## 3. Refill a watering can

Write a complete C++ program. Read the water already in a can, the amount added, and the amount poured onto plants, all in litres as decimal values from 0 to 10. The poured amount does not exceed the combined water. Store and print the litres remaining, without rounding to a whole number. Print no prompts.
